# Trinity Forms

A WordPress form builder where the useful stuff is free. That covers conditional logic, entry storage, CSV export and spam protection, with no caps on forms or submissions.

[Website](https://jnkplugins.com/trinity-forms/?utm_source=github) · [Demo video](https://www.youtube.com/watch?v=gpTBkVRzSqs) · [Download](https://license.jnkplugins.com/download/trinity-forms?src=github)

## What's free

- Build forms in a drag-and-drop Visual Builder (undo/redo, ready-made templates) or in the block editor
- File upload, pricing fields with a running total, multi-step forms, drafts
- Conditional logic with nested AND/OR groups, no limits
- Entries stored in your own database: search, stars, notes, bulk actions, trash
- CSV export
- Gravity Forms importer (forms, notifications and entries)
- Survey and poll results, quiz scoring
- Email notifications with merge tags
- Spam protection: honeypot, time-trap, Cloudflare Turnstile, reCAPTCHA or hCaptcha, optional Akismet
- Scheduling and entry limits, GDPR export/erase, a views-to-submissions funnel

Pro adds payments (Stripe, PayPal, Mollie), CRM and marketing integrations, signature, repeater and calculation fields, save and resume, PDF export, front-end entry views and more.

## Install

The easy way is the download page:

**[Download Trinity Forms free](https://license.jnkplugins.com/download/trinity-forms?src=github)**

Upload the zip under Plugins > Add New > Upload Plugin and activate it. The zip from that page has a free licence built in, so the plugin updates itself from your WordPress dashboard. You don't type in a key and you don't need an account. Email is optional.

You can also clone this repo into `wp-content/plugins/trinity-forms`. That copy works fine, but it **won't update itself**, because the licence comes with the download. Pull new tags yourself, or grab the zip above once and let it handle updates from then on.

Requires WordPress 6.2+ and PHP 8.2+.

## Updates and privacy

The download-page build checks `api.jnkplugins.com` for new versions. That request carries your site address, the free licence key and version numbers. Nothing else leaves your site: your form entries stay in your own database.
